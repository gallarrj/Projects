## GitHub Codespaces with n8n

This repository is configured with GitHub Codespaces to provide a ready-to-use n8n workflow automation environment.

### Quick Start

1. Click "Code" → "Codespaces" → "Create codespace on main"
2. Wait for the environment to initialize
3. Access n8n at the forwarded port 5678
4. Start building your automation workflows!

### What's Included

- **n8n**: Pre-installed workflow automation tool
- **Node.js 18**: Runtime environment  
- **Docker support**: For advanced workflow capabilities
- **VS Code extensions**: Enhanced development experience

For more details, see [.devcontainer/README.md](.devcontainer/README.md).
